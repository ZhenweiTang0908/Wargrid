# Wargrid 原创 3D 武将美术方向

## 视觉原则

Wargrid 使用“厚重汉末盔甲 + 清晰阵营轮廓 + 略夸张兵器”的原创 3D 风格。角色可以借鉴三国题材共有的历史服饰、甲胄结构和人物原型，但不复制其他游戏的构图、服装纹样、面容、卡牌边框或画师笔触。

四名首发角色的概念图位于 `public/heroes/`：

- `guan-yun.png`：青铜重甲、深青战袍、长柄偃月刀，强调主公威严。
- `zhao-ling.png`：绿白轻甲、长枪、高马尾，强调忠臣的迅捷与正直。
- `xiahou-lie.png`：黑红重甲、独眼、战损披风，强调反贼的压迫感。
- `sima-xuan.png`：紫灰文武袍甲、羽扇、锐利轮廓，强调内奸的隐秘与谋略。

## 建模规格

- 单个棋盘角色控制在 20k–35k 三角面；头像展示模型可使用 60k–90k 三角面。
- 统一人形骨骼和蒙皮规范，所有武将共享基础动作；武器与披风使用独立骨骼。
- 纹理采用一套 1024×1024 PBR 图集：Base Color、Normal、ORM。重要主角可升至 2048×2048。
- 输出格式统一为 glTF Binary（`.glb`），应用 Draco 或 Meshopt 压缩，并提供 50% 与 20% 面数的两级 LOD。
- 角色脚底原点置于世界原点，面朝 +Z；单位高度统一约 1.8 米，棋盘显示时按 0.8–1.0 米视觉高度缩放。

## 最小动画集

每个角色至少包含 `idle`、`walk`、`attack`、`cast`、`hit`、`heal`、`dying`、`death` 八段动作。动作事件在击中帧发送标记，卡牌结算与受击特效跟随事件同步。移动动画使用原地循环，由游戏逻辑沿路径驱动根节点。

## 制作流程

1. 以概念图建立正侧面比例稿，先锁定头身比、盔甲层次和武器轮廓。
2. Blender 完成中模、重拓扑、UV 和统一骨骼绑定。
3. Substance 3D Painter 或 Blender 完成 PBR 材质；阵营色集中在披风、束带和粒子光效。
4. 导出 GLB，在 Three.js 中检查材质、骨骼、动作名称、包围盒和移动端渲染开销。
5. 同屏四名武将时以 60 FPS 为基线，阴影只保留主方向光，远景切换 LOD。

当前代码中的程序化低模棋子作为碰撞、走位和动画占位。正式 GLB 接入后保持同一 `UnitPiece` 状态接口，不改动规则层。
